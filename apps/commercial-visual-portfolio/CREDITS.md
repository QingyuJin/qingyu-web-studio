# 素材與授權紀錄

最後更新：2026-07-28

本作品集中的攝影素材皆為本專案以 OpenAI 內建 ImageGen 工具原創生成，未使用第三方品牌商標、攝影圖庫或帶有浮水印的圖片。成品中的虛構品牌識別、中文文案、版面、裁切、介面與廣告組合皆為本專案原創設計。

## SOMME 肌理研究所

- 檔案：`public/images/somme-beauty.webp`
- 生成模式：OpenAI 內建 ImageGen
- 用途：高端肌膚管理 Campaign 原始攝影
- Prompt 摘要：暖奶油色攝影棚中的成年亞洲女性自然肌膚特寫、琥珀精華瓶、自然窗光、保留左側文案空間；無文字、無商標、無浮水印，避免塑膠感磨皮。
- 商品合成素材：`public/campaigns/sources/somme-products-cutout.png`
- 素材生成模式：OpenAI 內建 ImageGen；使用純色 Chroma Key 背景後於本地去背。
- 本地美工處理：瓶身去背、邊緣去綠、接觸陰影、人物與商品光色匹配、品牌標籤、成分資訊、價格與三尺寸重新構圖。

- 最終 Banner：`public/campaigns/final/`
- 製作過程：`public/campaigns/process/`
- 尺寸：每組包含 `1920×720`、`750×900`、`1080×1080` PNG。
- 輸出方式：以 Sharp 在本地完成攝影裁切、調色、去背素材合成、接觸陰影、品牌字標、資訊層級與高解析 PNG 光柵化。
