## 美術方向

A–D 不是四張裝飾圖，而是四種處理同一張照片的方式：照片露出多少、邊緣切得多硬。

| 方向 | 處理 |
| --- | --- |
| A 溶接 | 照片佔右側 46%，以漸層溶入紙白，沒有邊框與線條 |
| B 面板 | 照片收在上下留白的矩形內，右緣對齊內文 1160px 版心 |
| C 對開 | 照片滿版切齊右側 47%，分割線上一條銅色細線 |
| D 留白 | 照片壓到 62% 濃度、僅佔 23%，加一條橫貫版心的基準線 |

前一版的 A–D 是自製的向量多邊形（六角形、折板、層疊金屬片）。客戶反映過於模板化，已整批移除，不再使用任何裝飾性圖形。

## 色階統一

五頁的照片來源差異很大：有棚拍白底特寫，也有光線很平的廠房遠景。若只對齊平均亮度，暗調的廠房照會被整片拉灰、亮調的特寫則會過曝，兩者放在一起會明顯不成套。因此改為固定三個值：

| 項目 | 值 | 用意 |
| --- | --- | --- |
| 黑點 | 100 | 不壓到全黑，確保頁名永遠是畫面中最深的元素 |
| 白點 | 248 | 略高於紙白 `#f4f3f0`，亮部像受光金屬而不是破洞 |
| 平均 | 198 | 五頁的整體輕重一致 |

黑白點由色階映射固定，平均由一條指數曲線求解，對比再由一條兩端固定的 S 曲線調整（平的照片加強、太衝的收斂）。實測五頁：平均值差 4.4、白點差 2.0、對比差 21.3 — 剩下的差異就是照片本身的性格，不再是處理不一致。

另外加了極輕微的顆粒。放大後的像素過度平滑，那個「滑」正是低解析度的感覺；一點顆粒讀起來像印刷質地。

## 解析度說明

官網多數照片的原始尺寸只有 375×500 至 500×580。素材已改為只生成版面實際會用到的尺寸（桌機 900×600、手機 560×420 — 最寬的 A 方向在 1920 頁面上也只佔 46%，約 880px），把放大倍率從 3.2 倍降到 2.4 倍。只有「關於全泰」因為挖到 1920px 的原始檔，僅 1.6 倍。

目前以單色、統一色階、輕顆粒與適度銳化處理，在網頁上看不出來。但 2.4 倍仍是靠處理遮掩，不是真的銳利：**若客戶能提供原始高解析度檔案，Banner 的銳利度還能再明顯提升**，建議正式建置前先索取。若客戶願意補拍，料帶與成品件本身就很上相，值得專門拍一組。
