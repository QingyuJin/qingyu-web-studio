## 設計前提：黑 → 灰 → 黑

客戶官網原本是 黑（Header）→ **白**（內文）→ 黑（Footer）。往下滑時中間的白越夾越窄，黑白直接對撞，壓迫感由此而來。**這不是圖太少造成的** — 半版圖與滿版圖都試過，壓迫依舊存在。

解法是把中間那段的白換成**灰**，黑白硬碰撞就不存在了，再靠區塊化與留白把空間打開。灰色為客戶指定。

因此整套系統**只使用灰階與墨黑，不出現白**。在灰底上再放白色卡片等於把白搬回來，三個明度互打，反而更亂 — 這是中間一版走錯的路，已修正。

| 用途 | 色值 |
| --- | --- |
| 墨黑（Header／Footer／標題） | `#171717` |
| 主灰（Banner 底） | `#d9d5ce` |
| 深灰（錯位底板） | `#c8c4bc` |
| 淺灰（雙階下段） | `#e6e3dd` |
| 極淺灰（內文區） | `#edebe7` |

## 美術方向

A–D 不是四張裝飾圖，也不是同一張圖的四種裁切，而是**灰階與墨黑之間的四種構成**。

| 方向 | 做法 |
| --- | --- |
| A 墨題 | 左側 47% 一整塊墨黑承載頁名、白字反白，照片守住右側 41% 的灰，兩者硬碰硬接邊 |
| B 嵌塊 | 照片嵌成精確方塊，上下各留 17% 的灰，右緣對齊 1160px 版心；標題上方一道 46×5px 墨色短棒定錨 |
| C 雙階 | 主灰與淺灰在 64% 處硬邊分割，照片直立跨過接縫；標題整個抬到接縫之上，不騎線 |
| D 錯位 | 一塊深灰底板在後、照片錯開壓在其上，兩區塊交疊而非並排，不靠陰影做景深 |

前一版的 A–D 是自製向量多邊形（六角形、折板、層疊金屬片），客戶反映過於模板化。再前一版是同一張照片的四種裁切，差異太小。兩版都已重做。

## 色階統一

五頁的照片來源差異很大：有棚拍白底特寫，也有光線很平的廠房遠景。若只對齊平均亮度，暗調的廠房照會被整片拉灰、亮調的特寫則會過曝，兩者放在一起會明顯不成套。因此改為固定三個值：

| 項目 | 值 | 用意 |
| --- | --- | --- |
| 黑點 | 100 | 不壓到全黑，確保頁名永遠是畫面中最深的元素 |
| 白點 | 248 | 略高於紙白 `#f4f3f0`，亮部像受光金屬而不是破洞 |
| 平均 | 198 | 五頁的整體輕重一致 |

黑白點由色階映射固定，平均由一條指數曲線求解，對比再由一條兩端固定的 S 曲線調整（平的照片加強、太衝的收斂）。實測五頁：平均值差 4.4、白點差 2.0、對比差 21.3 — 剩下的差異就是照片本身的性格，不再是處理不一致。

另外加了極輕微的顆粒。放大後的像素過度平滑，那個「滑」正是低解析度的感覺；一點顆粒讀起來像印刷質地。

## 解析度說明

官網多數照片的原始尺寸只有 375×500 至 500×580。素材已改為只生成版面實際會用到的尺寸（桌機 900×600、手機 560×420 — 任何方向的區塊在 1920 頁面上都不超過約半版，900px 已足夠），把放大倍率從 3.2 倍降到 2.4 倍。只有「關於全泰」因為挖到 1920px 的原始檔，僅 1.6 倍。

目前以單色、統一色階、輕顆粒與適度銳化處理，在網頁上看不出來。但 2.4 倍仍是靠處理遮掩，不是真的銳利：**若客戶能提供原始高解析度檔案，Banner 的銳利度還能再明顯提升**，建議正式建置前先索取。若客戶願意補拍，料帶與成品件本身就很上相，值得專門拍一組。
