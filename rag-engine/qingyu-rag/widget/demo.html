Qingyu RAG 問答 Widget

右下角的聊天泡泡就是嵌入的 widget。這個範例頁面把 token-endpoint 指到假的 /mock-token-endpoint，實際串接時要換成 qingyuweb.com 自己後端的端點（見 example-token-endpoint.js）。

嵌入方式

<script src="qingyu-widget.js"></script>
<qingyu-chat-widget
  api-base="https://api.your-domain.com"
  token-endpoint="https://qingyuweb.com/api/widget-token"
  title="客服小幫手"
  theme-color="#4f46e5"
></qingyu-chat-widget>

屬性說明

  • api-base：RAG Engine 的 API 網址
  • token-endpoint：qingyuweb.com 自己後端的端點，回傳 {token, expires_in_seconds}
  • title：聊天視窗標題（選填）
  • theme-color：主色（選填，預設 #4f46e5）
  • welcome-message：開場白（選填）
